Secant Method — Solved Example

Question: Find a real root of

f(x) = x3 − x − 1 = 0
using the Secant Method with x0 = 1 and x1 = 2.
Stopping criterion: |xn+1 − xn| ≤ 0.001

Step 1 — Formula

xn+1 = xn − f(xn) × (xn − xn−1) f(xn) − f(xn−1)

Key: No derivative needed! Uses two previous points instead.

Step 2 — Starting Values

x0 = 1    →    f(1) = (1)3 − 1 − 1 = −1

x1 = 2    →    f(2) = (2)3 − 2 − 1 = 8 − 3 = +5

Step 3 — Iterations

Iteration 1: Compute x2

x0 = 1,   x1 = 2,   f(x0) = −1,   f(x1) = 5

x2 = x1 − f(x1) × (x1 − x0) f(x1) − f(x0)

x2 = 2 − 5 × (2 − 1) 5 − (−1) = 2 − 5 × 1 6 = 2 − 0.83333 = 1.16667

f(1.16667) = (1.16667)3 − 1.16667 − 1 = 1.5880 − 2.1667 = −0.5787

|x2 − x1| = |1.16667 − 2| = 0.83333 > 0.001 → continue

Iteration 2: Compute x3

x1 = 2,   x2 = 1.16667,   f(x1) = 5,   f(x2) = −0.5787

x3 = 1.16667 − (−0.5787) × (1.16667 − 2) (−0.5787) − 5

x3 = 1.16667 − (−0.5787) × (−0.83333) −5.5787

x3 = 1.16667 − (−0.5787)(0.14937)
x3 = 1.16667 + 0.08646 = 1.25311

f(1.25311) = (1.25311)3 − 1.25311 − 1 = −0.28537

|x3 − x2| = 0.08644 > 0.001 → continue

Iteration 3: Compute x4

x2 = 1.16667,   x3 = 1.25311,   f(x2) = −0.5787,   f(x3) = −0.28537

x4 = 1.25311 − (−0.28537) × (1.25311 − 1.16667) (−0.28537) − (−0.5787)

x4 = 1.25311 − (−0.28537) × 0.08644 0.29333

x4 = 1.25311 + 0.08412 = 1.33721

f(1.33721) = (1.33721)3 − 1.33721 − 1 = 0.05390

|x4 − x3| = 0.08410 > 0.001 → continue

Iteration 4: Compute x5

x3 = 1.25311,   x4 = 1.33721,   f(x3) = −0.28537,   f(x4) = 0.05390

x5 = 1.33721 − (0.05390) × (1.33721 − 1.25311) 0.05390 − (−0.28537)

x5 = 1.33721 − 0.05390 × 0.08410 0.33927

x5 = 1.33721 − 0.01337 = 1.32385

f(1.32385) = −0.0037

|x5 − x4| = 0.01336 > 0.001 → continue

Iteration 5: Compute x6

x4 = 1.33721,   x5 = 1.32385,   f(x4) = 0.05390,   f(x5) = −0.0037

x6 = 1.32385 − (−0.0037) × (1.32385 − 1.33721) (−0.0037) − (0.05390)

x6 = 1.32385 − (−0.0037) × −0.01336 −0.05760

x6 = 1.32385 − 0.00086 = 1.32471

|x6 − x5| = 0.00086 < 0.001 → STOP!

The real root of x3 − x − 1 = 0 is approximately x ≈ 1.325
(Same answer as Newton-Raphson, but NO derivative needed!)

Easy Words

  • Pick two starting guesses x0 and x1
  • Apply formula using last two x values and their f values
  • Shift: drop the oldest x, keep the newest two
  • Stop when |xnew − xold| ≤ 0.001
  • Advantage: No derivative needed (unlike Newton-Raphson)
