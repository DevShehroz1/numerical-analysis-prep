Bisection Method — Solved Example

Question: Find a real root of

f(x) = x3 − x − 1 = 0
using the Bisection Method, correct to 3 decimal places.

Stopping criterion: |xnew − xold| < 0.001

Step 1 — Formula

c = (a + b) / 2     (take the midpoint)

Rule: f(a) and f(b) must have opposite signs.

Step 2 — Find Initial Interval [a, b]

xf(x) = x3 − x − 1Sign
00 − 0 − 1 = −1negative
11 − 1 − 1 = −1negative
28 − 2 − 1 = +5positive
Sign changes between x = 1 and x = 2, so root lies in [1, 2]

Step 3 — Iterations

Iteration 1

a = 1,   b = 2,   f(a) = −1,   f(b) = +5

c = (1 + 2) / 2 = 1.5

f(1.5) = (1.5)3 − 1.5 − 1 = 3.375 − 2.5 = +0.875

Check: f(a) × f(c) = (−1)(+0.875) = −0.875 < 0 → opposite signs
Root is in [a, c] → set b = 1.5

Iteration 2

a = 1,   b = 1.5

c = (1 + 1.5) / 2 = 1.25

f(1.25) = (1.25)3 − 1.25 − 1 = 1.953 − 2.25 = −0.297

Check: f(a) × f(c) = (−1)(−0.297) = +0.297 > 0 → same signs
Root is in [c, b] → set a = 1.25

Iteration 3

a = 1.25,   b = 1.5

c = (1.25 + 1.5) / 2 = 1.375

f(1.375) = (1.375)3 − 1.375 − 1 = 2.600 − 2.375 = +0.224

f(a) × f(c) = (−0.297)(+0.224) < 0 → opposite signs
Root is in [a, c] → set b = 1.375

Iteration 4

a = 1.25,   b = 1.375

c = (1.25 + 1.375) / 2 = 1.3125

f(1.3125) = (1.3125)3 − 1.3125 − 1 = 2.260 − 2.3125 = −0.051

f(a) × f(c) = (−0.297)(−0.051) > 0 → same signs
Root is in [c, b] → set a = 1.3125

Iteration 5

a = 1.3125,   b = 1.375

c = (1.3125 + 1.375) / 2 = 1.3438

f(1.3438) = +0.082

Opposite signs → set b = 1.3438

Iteration 6

a = 1.3125,   b = 1.3438

c = (1.3125 + 1.3438) / 2 = 1.3281

f(1.3281) = +0.014

Opposite signs → set b = 1.3281

Iteration 7

a = 1.3125,   b = 1.3281

c = (1.3125 + 1.3281) / 2 = 1.3203

f(1.3203) = −0.018

Same signs as f(a) → set a = 1.3203

Iteration 8

a = 1.3203,   b = 1.3281

c = (1.3203 + 1.3281) / 2 = 1.3242

f(1.3242) = −0.002

|cnew − cold| = |1.3242 − 1.3203| = 0.0039 > 0.001 → continue

Iteration 9

a = 1.3242,   b = 1.3281

c = (1.3242 + 1.3281) / 2 = 1.3262

|cnew − cold| = |1.3262 − 1.3242| = 0.002 > 0.001 → continue

Iteration 10

c = 1.3252

|cnew − cold| = |1.3252 − 1.3262| = 0.001 → STOP

How to Decide (Easy Rule)

  • If f(a) × f(c) < 0 (opposite signs) → root is in [a, c] → b = c
  • If f(a) × f(c) > 0 (same signs) → root is in [c, b] → a = c
  • If f(c) = 0 → c IS the root, STOP
