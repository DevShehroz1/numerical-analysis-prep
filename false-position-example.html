False Position Method — Solved Example (up to 2 decimal places)

Question: Find a real root of
f(x) = x³ − 2x − 5 = 0
using the False Position Method, correct to 2 decimal places.

Step 1 — Formula

x₁ = ( a · f(b) − b · f(a) ) / ( f(b) − f(a) )

Rule: f(a) and f(b) must have opposite signs.

Step 2 — Find Initial Interval [a, b]

xf(x) = x³ − 2x − 5Sign
28 − 4 − 5 = −1negative
327 − 6 − 5 = +16positive ✓
Sign changes between 2 and 3, so root lies in [2, 3].

Start with: a = 2, b = 3, f(a) = −1, f(b) = 16

Step 3 — Iterations

Iteration 1

a = 2,   b = 3,   f(a) = −1,   f(b) = 16

x₁ = (2 × 16 − 3 × (−1)) / (16 − (−1))
x₁ = (32 + 3) / 17 = 35 / 17 = 2.06

f(2.06) = (2.06)³ − 2(2.06) − 5
    = 8.7418 − 4.12 − 5 = −0.378

Negative → replace a with 2.06.

Iteration 2

a = 2.06,   b = 3,   f(a) = −0.378,   f(b) = 16

x₂ = (2.06 × 16 − 3 × (−0.378)) / (16 + 0.378)
x₂ = (32.96 + 1.134) / 16.378 = 34.094 / 16.378 = 2.08

f(2.08) = (2.08)³ − 2(2.08) − 5
    = 8.9989 − 4.16 − 5 = −0.161

Negative → replace a with 2.08.

Iteration 3

a = 2.08,   b = 3,   f(a) = −0.161,   f(b) = 16

x₃ = (2.08 × 16 − 3 × (−0.161)) / (16 + 0.161)
x₃ = (33.28 + 0.483) / 16.161 = 33.763 / 16.161 = 2.09

f(2.09) = (2.09)³ − 2(2.09) − 5
    = 9.1294 − 4.18 − 5 = −0.051

Negative → replace a with 2.09.

Iteration 4

a = 2.09,   b = 3,   f(a) = −0.051,   f(b) = 16

x₄ = (2.09 × 16 − 3 × (−0.051)) / 16.051
x₄ = (33.44 + 0.153) / 16.051 = 33.593 / 16.051 = 2.09

The value is same as previous (2.09).

Step 5 — Stop

x₃ = 2.09 and x₄ = 2.09 → answer is stable to 2 decimal places. STOP.

✓ The real root of x³ − 2x − 5 = 0 is approximately x ≈ 2.09

Easy Words

  • Pick two values where f changes sign.
  • Apply formula → get new x.
  • Replace the side that has the same sign as the new f(x).
  • Stop when the digits you need stop changing.
