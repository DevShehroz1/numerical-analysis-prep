Topic 1Bisection Method

The simplest and most reliable way to find where a function equals zero — just keep cutting the interval in half.

Why Do We Need This?

Some equations are easy: 2x + 4 = 0 gives x = −2. But many real-world equations have no simple formula:

Example equations you can't solve by hand:

x³ − x − 1 = 0  |  eˣ − x = 0  |  ln(x) + x − 2 = 0

These need numerical methods — algorithms that get closer and closer to the answer through repeated calculations (iterations).

The Core Idea

Imagine you're playing a number guessing game. Someone picks a number between 1 and 100. You guess 50. They say "higher." You guess 75. They say "lower." You guess 62... and so on. Each guess cuts your range in half.

The Intermediate Value Theorem: If f(a) is negative and f(b) is positive (or vice versa), and f is continuous, then there MUST be a root (zero) somewhere between a and b.

Mathematically: if f(a) × f(b) < 0, a root exists in [a, b].

The Formula

Bisection Formula
c = (a + b) / 2

That's it — just the midpoint!

The Algorithm — Step by Step

1
Choose a and b such that f(a) × f(b) < 0 (opposite signs). Try plugging in integers: 0, 1, 2, 3... until you find a sign change.
2
Compute midpoint: c = (a + b) / 2
3
Evaluate f(c) and decide:
• If f(a) × f(c) < 0 → root is in [a, c] → set b = c
• If f(a) × f(c) > 0 → root is in [c, b] → set a = c
• If f(c) = 0 → c IS the root! Stop.
4
Repeat until you meet the stopping criterion: |c_new − c_old| < ε or after n iterations.
Minimum iterations formula:
n ≥ log((b − a) / ε) / log(2)
This tells you how many iterations you need for a given accuracy ε.

Topic 2False Position Method

Also called Regula Falsi — a smarter version of Bisection that uses a straight line instead of just the midpoint.

How Is It Different From Bisection?

Bisection Method
  • Always picks the MIDPOINT
  • Ignores how close f(a) or f(b) are to zero
  • Simple but slow
False Position Method
  • Draws a LINE between (a, f(a)) and (b, f(b))
  • Picks where the line crosses x-axis
  • Usually faster convergence
Key Insight: If f(a) is very close to zero but f(b) is far from zero, the root is probably closer to a. False Position takes this into account; Bisection doesn't.

The Formula

False Position Formula
x_r = b − f(b) × (a − b) / (f(a) − f(b))

Alternative form (equivalent):

Alternative Form
x_r = (a × f(b) − b × f(a)) / (f(b) − f(a))

The Algorithm

1
Choose a and b such that f(a) × f(b) < 0 (same as Bisection)
2
Compute x_r using the formula above (NOT midpoint!)
3
Check signs — same logic as Bisection:
• If f(a) × f(x_r) < 0 → root in [a, x_r] → set b = x_r
• If f(a) × f(x_r) > 0 → root in [x_r, b] → set a = x_r
4
Repeat until stopping criterion is met.

Worked Example

f(x) = x³ − x − 2 = 0  (tolerance ε = 0.001) ▼

Step 1: Find interval

f(1) = 1 − 1 − 2 = −2  |  f(2) = 8 − 2 − 2 = +4

Root in [1, 2]

Step 2: Iteration 1 — in detail

a = 1, b = 2, f(a) = −2, f(b) = +4

x_r = b − f(b)×(a−b) / (f(a)−f(b))

x_r = 2 − 4×(1−2) / (−2−4)

x_r = 2 − 4×(−1) / (−6)

x_r = 2 − (−4)/(−6) = 2 − 0.6667 = 1.33333

f(1.33333) = (1.33333)³ − 1.33333 − 2 = −0.96298

f(a) × f(x_r) = (−2)(−0.96298) = +1.926 > 0 → root in [1.33333, 2]

Set a = 1.33333

Topic 3Newton-Raphson Method

The fastest root-finding method — uses the tangent line at a point to zoom in on the root. Requires the derivative f'(x).

The Big Difference

Bisection & False Position
  • Need TWO starting points (a and b)
  • Called "bracketing" methods
  • Slow but guaranteed to work
Newton-Raphson
  • Need only ONE starting point (x₀)
  • Called an "open" method
  • Very fast but can fail sometimes
  • Needs the derivative f'(x)

The Idea

At any point x₀, draw the tangent line to the curve. Where that tangent line hits the x-axis is your next guess x₁. Repeat.

The Formula

Newton-Raphson Formula
x_{n+1} = xₙ − f(xₙ) / f'(xₙ)
You MUST know the derivative!
For f(x) = x³ − x − 1 → f'(x) = 3x² − 1
For f(x) = eˣ − x → f'(x) = eˣ − 1
For f(x) = x³ − 2x − 5 → f'(x) = 3x² − 2

The Algorithm

1
Choose initial guess x₀ — pick a value near the root (check f(0), f(1), f(2)... and pick the one closest to zero)
2
Compute f(x₀) and f'(x₀)
3
Apply formula: x₁ = x₀ − f(x₀)/f'(x₀)
4
Repeat until |xₙ₊₁ − xₙ| < ε

Worked Example

f(x) = x³ − x − 1 = 0, f'(x) = 3x² − 1, stopping: |xₙ₊₁ − xₙ| < 0.001 ▼

Step 1: Choose x₀

f(0) = −1, f(1) = −1, f(2) = +5

f(1) = −1 is nearest to zero → x₀ = 1

Iteration 1: Compute x₁

f(x₀) = f(1) = 1 − 1 − 1 = −1

f'(x₀) = f'(1) = 3(1)² − 1 = 2

x₁ = x₀ − f(x₀)/f'(x₀) = 1 − (−1)/2 = 1 + 0.5 = 1.5

|x₁ − x₀| = |1.5 − 1| = 0.5 > 0.001 → continue

Iteration 2: Compute x₂

f(1.5) = (1.5)³ − 1.5 − 1 = 3.375 − 2.5 = 0.875

f'(1.5) = 3(1.5)² − 1 = 6.75 − 1 = 5.75

x₂ = 1.5 − 0.875/5.75 = 1.5 − 0.15217 = 1.34783

|x₂ − x₁| = 0.15217 > 0.001 → continue

Iteration 3: Compute x₃

f(1.34783) = (1.34783)³ − 1.34783 − 1 = 0.1007

f'(1.34783) = 3(1.34783)² − 1 = 4.44994

x₃ = 1.34783 − 0.1007/4.44994 = 1.32520

|x₃ − x₂| = 0.02263 > 0.001 → continue

Iteration 4: Compute x₄

f(1.32520) = 0.00306

f'(1.32520) = 4.26847

x₄ = 1.32520 − 0.00306/4.26847 = 1.32472

|x₄ − x₃| = 0.00048 < 0.001 ✓ STOP!

Answer: x ≈ 1.325 (only 4 iterations! Bisection needed 8+)

Topic 4Secant Method

Like Newton-Raphson but WITHOUT needing the derivative — it approximates the derivative using two previous points.

Why Secant?

Problem with Newton-Raphson: You need f'(x), which can be hard or impossible to compute for complicated functions.
Solution: The Secant Method approximates f'(x) using two points — no derivative needed!

The Formula

Secant Method Formula
x_{n+1} = xₙ − f(xₙ) × (xₙ − x_{n-1}) / (f(xₙ) − f(x_{n-1}))
Needs TWO initial guesses: x₀ and x₁ (but they do NOT need to bracket the root like Bisection/False Position)

The Algorithm

1
Choose x₀ and x₁ — two initial guesses near the root
2
Compute: x₂ = x₁ − f(x₁) × (x₁ − x₀) / (f(x₁) − f(x₀))
3
Shift: x₀ becomes old x₁, x₁ becomes x₂
4
Repeat until |xₙ₊₁ − xₙ| < ε

Worked Example

f(x) = x³ − x − 1 = 0, x₀ = 1, x₁ = 2, stopping: |xₙ₊₁ − xₙ| < 0.001 ▼

Setup

f(1) = −1,   f(2) = 5

Iteration 1: Compute x₂

x₂ = x₁ − f(x₁) × (x₁ − x₀) / (f(x₁) − f(x₀))

x₂ = 2 − 5 × (2 − 1) / (5 − (−1))

x₂ = 2 − 5/6 = 1.1667

f(1.1667) = (1.1667)³ − 1.1667 − 1 = −0.5797

|x₂ − x₁| = 0.8333 > 0.001

Iteration 2: Compute x₃

Now x₀ = 2, x₁ = 1.1667

x₃ = 1.1667 − (−0.5797)(1.1667 − 2) / (−0.5797 − 5)

x₃ = 1.1667 − (−0.5797)(−0.8333) / (−5.5797)

x₃ = 1.1667 + 0.0866 = 1.2533

Continuing iterations:

Topic 5Gauss Elimination Method

Solving systems of linear equations — convert the matrix to upper triangular form, then solve backwards.

What Problem Does This Solve?

Given a system of equations like:

2x + y − z = 8
−3x − y + 2z = −11
−2x + y + 2z = −3

We want to find x, y, and z. Gauss Elimination converts this to a triangular system that's easy to solve.

The Idea

Two phases:
1. Forward Elimination: Turn the system into upper triangular form (zeros below diagonal)
2. Back Substitution: Solve from the bottom row up

Step-by-Step Process

Phase 1: Write the Augmented Matrix

Write the coefficients and constants as a matrix:

  • ✅ Add a multiple of one row to another row

Topic 6Gauss-Jordan Elimination

An extension of Gauss Elimination — reduce all the way to the identity matrix so you can read off the answers directly. No back substitution needed!

How Is It Different From Gauss?

Gauss Elimination
  • Makes zeros BELOW diagonal only
  • Gets upper triangular form
  • Needs back substitution
  • Faster to compute
Gauss-Jordan
  • Makes zeros ABOVE and BELOW diagonal
  • Gets reduced row echelon form (identity)
  • Read answers directly — no back sub!
  • More row operations needed

The Goal

Target Form
[1 0 0 | answer₁]   [0 1 0 | answer₂]   [0 0 1 | answer₃]

Exam tip: If the question says "Gauss Elimination" → stop at upper triangular, do back substitution.

Interval is now [1.3242, 1.3281] — only 0.004 wide!
Root ≈ 1.324 (correct to 3 decimal places)

The Decision Rule — Summary

After computing c and f(c), ask ONE question:

Does f(a) × f(c) give a NEGATIVE number?
→ YES (negative): root is between a and c → b = c (throw away right half)
→ NO (positive): root is between c and b → a = c (throw away left half)

Negative × Negative = Positive (same side, no root between them)
Negative × Positive = Negative (different sides, root IS between them)

Learn by DoingFalse Position: Step by Step

Solve f(x) = x³ − x − 2 = 0 with the False Position method. Every calculation shown.

Our function: f(x) = x³ − x − 2

Key difference from Bisection: Instead of midpoint, we draw a line and find where it crosses zero.

Formula: x_r = b − f(b) × (a − b) / (f(a) − f(b))

f(1) = 1 − 1 − 2 = −2, f(2) = 8 − 2 − 2 = +4 → Start with a=1, b=2

ITER 1 a = 1, b = 2, f(a) = −2, f(b) = +4
🔢
Compute x_r (NOT midpoint!):
x_r = b − f(b) × (a − b) / (f(a) − f(b))
x_r = 2 − (+4) × (1 − 2) / (−2 − 4)
x_r = 2 − (4)(−1) / (−6)
x_r = 2 − (−4)/(−6)
x_r = 2 − 0.6667 = 1.3333
Notice: this is NOT 1.5 (the midpoint). It's pulled closer to a because f(a) is closer to zero.
🔢
f(1.3333) = (1.3333)³ − 1.3333 − 2 = 2.3704 − 1.3333 − 2 = −0.9630
🤔
f(a) × f(x_r) = (−2)(−0.963) = +1.926 > 0 → Same sign!
Root in [x_r, b] = [1.3333, 2] → a becomes 1.3333
⬇
ITER 2 a = 1.3333, b = 2, f(a) = −0.963, f(b) = +4
🔢
x_r = 2 − 4 × (1.3333 − 2) / (−0.963 − 4)
= 2 − 4 × (−0.6667) / (−4.963)
= 2 − (−2.6667)/(−4.963)
= 2 − 0.5373 = 1.4627
🔢
f(1.4627) = (1.4627)³ − 1.4627 − 2 = −0.3333
🤔
f(a) × f(x_r) = (−0.963)(−0.333) = positive → Same sign!
Root in [x_r, b] → a becomes 1.4627, b stays 2
⬇

Pattern continues... after 7 iterations: x ≈ 1.521

Key observation: Notice how b=2 never changed! In False Position, sometimes one endpoint gets "stuck." This is a known drawback compared to Bisection.

Learn by DoingNewton-Raphson: Step by Step

Solve f(x) = x³ − x − 1 = 0 using Newton-Raphson. Watch how fast it converges!

f(x) = x³ − x − 1 → f'(x) = 3x² − 1 (derivative: bring power down, reduce by 1)

Formula: x_{n+1} = xₙ − f(xₙ) / f'(xₙ)

Starting guess: x₀ = 1 (because f(1)=−1 is closest to 0)

ITER 1 x₀ = 1
🔢
f(x₀) = f(1) = (1)³ − 1 − 1 = 1 − 1 − 1 = −1
🔢
f'(x₀) = f'(1) = 3(1)² − 1 = 3 − 1 = 2
📐
x₁ = x₀ − f(x₀)/f'(x₀)
= 1 − (−1)/2
= 1 − (−0.5)
= 1 + 0.5 = 1.5
|x₁ − x₀| = |1.5 − 1| = 0.5 > 0.001 → continue
⬇
ITER 2 x₁ = 1.5
🔢
f(1.5) = (1.5)³ − 1.5 − 1 = 3.375 − 2.5 = 0.875
🔢
f'(1.5) = 3(1.5)² − 1 = 3(2.25) − 1 = 6.75 − 1 = 5.75
📐
x₂ = 1.5 − 0.875/5.75 = 1.5 − 0.15217 = 1.34783
|x₂ − x₁| = 0.15217 > 0.001 → continue
⬇
ITER 3 x₂ = 1.34783
🔢
f(1.34783) = (1.34783)³ − 1.34783 − 1 = 2.44802 − 2.34783 = 0.1007
🔢
f'(1.34783) = 3(1.34783)² − 1 = 3(1.81665) − 1 = 4.44994
📐
x₃ = 1.34783 − 0.1007/4.44994 = 1.34783 − 0.02263 = 1.32520
|x₃ − x₂| = 0.02263 > 0.001 → continue
⬇
ITER 4 x₃ = 1.32520
🔢
f(1.3252) = 0.00306 | f'(1.3252) = 4.26847
🎯
x₄ = 1.3252 − 0.00306/4.26847 = 1.32472
|x₄ − x₃| = 0.00048 < 0.001 ✅ CONVERGED!

Root ≈ 1.325 — Only 4 iterations! (Bisection needed 8+)

Learn by DoingSecant Method: Step by Step

Solve f(x) = x³ − x − 1 = 0 using the Secant Method. No derivative needed!

Formula: x_{n+1} = xₙ − f(xₙ) × (xₙ − x_{n-1}) / (f(xₙ) − f(x_{n-1}))

Starting: x₀ = 1, x₁ = 2

f(1) = −1, f(2) = 5

ITER 1 x₀ = 1, x₁ = 2
🔢
x₂ = x₁ − f(x₁) × (x₁ − x₀) / (f(x₁) − f(x₀))
= 2 − 5 × (2 − 1) / (5 − (−1))
= 2 − 5 × 1 / 6
= 2 − 0.8333 = 1.1667
🔢
f(1.1667) = (1.1667)³ − 1.1667 − 1 = −0.5797
⬇
ITER 2 x₁ = 2, x₂ = 1.1667
📥
Important: Now xₙ₋₁ = x₁ = 2 and xₙ = x₂ = 1.1667
f(2) = 5, f(1.1667) = −0.5797
🔢
x₃ = 1.1667 − (−0.5797) × (1.1667 − 2) / (−0.5797 − 5)
= 1.1667 − (−0.5797)(−0.8333) / (−5.5797)
= 1.1667 − 0.4831 / (−5.5797)
= 1.1667 + 0.0866 = 1.2533
⬇

The pattern: Each iteration uses the two most recent x values. After 5-6 iterations: x ≈ 1.3247

Key difference from Newton: Newton needs f'(x) (derivative). Secant approximates it using two points — no calculus needed, just slightly slower.

Learn by DoingGauss & Gauss-Jordan Practice

Solve a system of equations step by step, seeing every row operation.

Problem: Solve this system

x + y + z = 6
2x + 3y + z = 14
x + y + 2z = 9
STEP 1 Write the augmented matrix
📝
Write coefficients of x, y, z and the constants on the right:

[ 1   1   1  |  6  ]   ← from x + y + z = 6
[ 2   3   1  |  14 ]   ← from 2x + 3y + z = 14
[ 1   1   2  |  9  ]   ← from x + y + 2z = 9
⬇
STEP 2 Eliminate x from Row 2 and Row 3
🔢
R₂ = R₂ − 2×R₁ (to make the "2" in R2 become 0)
[2−2(1), 3−2(1), 1−2(1), 14−2(6)] = [0, 1, −1, 2]
🔢
R₃ = R₃ − 1×R₁ (to make the "1" in R3 become 0)
[1−1, 1−1, 2−1, 9−6] = [0, 0, 1, 3]
📋
[ 1   1   1  |  6 ]
[ 0   1  −1  |  2 ]
[ 0   0   1  |  3 ]

This is already upper triangular! (Lucky — sometimes you need more steps)
⬇
STEP 3 Back Substitution (Gauss Elimination stops here)
3️⃣
From Row 3: 1×z = 3 → z = 3
2️⃣
From Row 2: y − z = 2 → y − 3 = 2 → y = 5
1️⃣
From Row 1: x + y + z = 6 → x + 5 + 3 = 6 → x = −2

For Gauss-Jordan: Continue to Identity Matrix

After reaching upper triangular, Gauss-Jordan continues to eliminate entries ABOVE the diagonal too, making each pivot = 1 and everything else = 0.

STEP 4 Eliminate above diagonal
🔢
R₂ = R₂ + R₃ (eliminate z from Row 2)
[0, 1, −1+1, 2+3] = [0, 1, 0, 5]
🔢
R₁ = R₁ − R₃ (eliminate z from Row 1)
[1, 1, 1−1, 6−3] = [1, 1, 0, 3]
🔢
R₁ = R₁ − R₂ (eliminate y from Row 1)
[1, 1−1, 0, 3−5] = [1, 0, 0, −2]
🎯
[ 1   0   0  |  −2 ] → x = −2
[ 0   1   0  |  5  ] → y = 5
[ 0   0   1  |  3  ] → z = 3

Read answers directly from the last column!
Both methods give: x = −2, y = 5, z = 3
