Newton-Raphson Method — Solved Example

Question: Find a real root of

f(x) = x3 − x − 1 = 0
using the Newton-Raphson Method.
Stopping criterion: |xn+1 − xn| ≤ 0.001

Step 1 — Formula

xn+1 = xn − f(xn) f′(xn)

Step 2 — Find f(x) and f′(x)

f(x) = x3 − x − 1

f′(x) = 3x2 − 1    (derivative: bring the power down, reduce by 1)

Step 3 — Choose Initial Guess x0

xf(x)Close to zero?
00 − 0 − 1 = −1yes
11 − 1 − 1 = −1yes
28 − 2 − 1 = +5no
f(1) = −1 is closest to zero → choose x0 = 1

Step 4 — Iterations

Iteration 1: Compute x1

x0 = 1

f(x0) = f(1) = (1)3 − 1 − 1 = 1 − 1 − 1 = −1

f′(x0) = f′(1) = 3(1)2 − 1 = 3 − 1 = 2

x1 = x0 − f(x0) f′(x0) = 1 − (−1) 2 = 1 + 0.5 = 1.5

|x1 − x0| = |1.5 − 1| = 0.5 > 0.001 → continue

Iteration 2: Compute x2

x1 = 1.5

f(1.5) = (1.5)3 − 1.5 − 1 = 3.375 − 2.5 = 0.875

f′(1.5) = 3(1.5)2 − 1 = 3(2.25) − 1 = 6.75 − 1 = 5.75

x2 = 1.5 − 0.875 5.75 = 1.5 − 0.15217 = 1.34783

|x2 − x1| = |1.34783 − 1.5| = 0.15217 > 0.001 → continue

Iteration 3: Compute x3

x2 = 1.34783

f(1.34783) = (1.34783)3 − 1.34783 − 1
    = 2.44802 − 2.34783 = 0.1007

f′(1.34783) = 3(1.34783)2 − 1 = 3(1.81665) − 1 = 5.44994 − 1 = 4.44994

x3 = 1.34783 − 0.1007 4.44994 = 1.34783 − 0.02263 = 1.32520

|x3 − x2| = |1.32520 − 1.34783| = 0.02263 > 0.001 → continue

Iteration 4: Compute x4

x3 = 1.32520

f(1.32520) = (1.32520)3 − 1.32520 − 1 = 0.00306

f′(1.32520) = 3(1.32520)2 − 1 = 3(1.75614) − 1 = 5.26847 − 1 = 4.26847

x4 = 1.32520 − 0.00306 4.26847 = 1.32520 − 0.00072 = 1.32472

|x4 − x3| = |1.32472 − 1.32520| = 0.00048 < 0.001 → STOP!

The real root of x3 − x − 1 = 0 is approximately x ≈ 1.325
(Only 4 iterations! Bisection needed 8+)

Easy Words

  • Find the derivative f′(x) first
  • Pick a starting guess x0 (the one closest to zero)
  • Apply formula: xnew = xold − f(x) / f′(x)
  • Stop when |xnew − xold| ≤ 0.001
