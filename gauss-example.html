Gauss Elimination — Solved Example

Question: Solve the system of linear equations:
2x + y − z = 8
−3x − y + 2z = −11
−2x + y + 2z = −3
using Gauss Elimination.

Step 1 — Convert to Matrix Form (AX = B)

Coefficient matrix A, unknowns X, constants B:
A = [ 2 1 -1 ] X = [ x ] B = [ 8 ] [ -3 -1 2 ] [ y ] [-11 ] [ -2 1 2 ] [ z ] [ -3 ]

Step 2 — Write Augmented Matrix [A | B]

[ 2 1 -1 | 8 ] ← R1 [ -3 -1 2 | -11] ← R2 [ -2 1 2 | -3 ] ← R3
Goal: Use row operations to turn the left side into upper triangular form (zeros below the diagonal). Then use back substitution.

Step 3 — Forward Elimination

Pivot = R1 (first row), pivot element = 2

Eliminate x from R2 and R3 using R1.

R2 ← R2 + (3/2)·R1

[−3, −1, 2, −11] + (3/2)·[2, 1, −1, 8]
= [−3, −1, 2, −11] + [3, 1.5, −1.5, 12]
= [0, 0.5, 0.5, 1]
R3 ← R3 + R1

[−2, 1, 2, −3] + [2, 1, −1, 8]
= [0, 2, 1, 5]

Matrix after first elimination:

[ 2 1 -1 | 8 ] [ 0 0.5 0.5 | 1 ] [ 0 2 1 | 5 ]

Pivot = R2 (second row), pivot element = 0.5

Eliminate y from R3 using R2.

R3 ← R3 − 4·R2
(because 2 / 0.5 = 4)

[0, 2, 1, 5] − 4·[0, 0.5, 0.5, 1]
= [0, 2, 1, 5] − [0, 2, 2, 4]
= [0, 0, −1, 1]

Matrix now in upper triangular form:

[ 2 1 -1 | 8 ] [ 0 0.5 0.5 | 1 ] [ 0 0 -1 | 1 ]

Step 4 — Back Substitution

From Row 3:
−z = 1
z = −1
From Row 2:
0.5y + 0.5z = 1
0.5y + 0.5(−1) = 1
0.5y − 0.5 = 1
0.5y = 1.5
y = 3
From Row 1:
2x + y − z = 8
2x + 3 − (−1) = 8
2x + 3 + 1 = 8
2x + 4 = 8
2x = 4
x = 2
Solution: x = 2,   y = 3,   z = −1

Step 5 — Verification (check answer in original equations)

Equation 1: 2x + y − z = 8
2(2) + 3 − (−1) = 4 + 3 + 1 = 8 ✓
Equation 2: −3x − y + 2z = −11
−3(2) − 3 + 2(−1) = −6 − 3 − 2 = −11 ✓
Equation 3: −2x + y + 2z = −3
−2(2) + 3 + 2(−1) = −4 + 3 − 2 = −3 ✓
All three equations satisfied! Unique solution: (x, y, z) = (2, 3, −1)

Easy Words — Steps to Remember

  1. Write the augmented matrix [A | B]
  2. Forward elimination: Make zeros below each diagonal element (use row operations)
    • Pick a pivot (diagonal element)
    • Use that row to kill the numbers below it
  3. Continue until you have upper triangular form (zeros below diagonal)
  4. Back substitution: Start from the last row, solve for each variable going up
  5. Verify: Plug the answers back into original equations

Row Operations Allowed

  • Swap two rows
  • Multiply a row by a non-zero constant
  • Add a multiple of one row to another row
